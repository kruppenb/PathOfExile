## Layout

```
leagues/   one file per league worth knowing about + a history table
tools/     build planners, meta sites, trade, filters, overlays
strategy/  leveling and atlas/farming principles
builds/    selection framework, candidate list, player profile, chosen build(s)
```

## Conventions

- Mark claims from a single third-party source as *(single source)*; prefer GGG patch notes, poe.ninja, and established guide sites.
- Date every snapshot (meta data goes stale fast).
- When a build is chosen, add `builds/<league>-<build>.md` with the PoB link, leveling plan, gear path and atlas plan.
