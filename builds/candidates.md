# 3.30 starter candidates (pre-patch-notes)

**Status:** Built from 3.29 end-of-league data and pre-3.30 tier lists. **None are 3.30-tested.** Re-rate after patch notes.
Sources are mostly RMT-shop blogs and aggregators, so weigh the "consensus" column more than any single tier.

Legend: ✅ = appears on several lists · ⚠ = nerf risk or gear concerns

## Higher ceiling / not ideal day 1
- **Luminary "Flame Link mercenary"** (Scion / Luminary): called the build of 3.29; ⚠ widely expected to be nerfed.
- **Strength Stacker Juggernaut** (Glacial Hammer of Shattering): great later, needs gear.
- **Herald Stacker Elementalist autobomber**: cheap start but scaling needs ~50 div.
- **CoC Forbidden Rite**: not online until high 80s.
- **Cyclone (of Tumult) Slayer**: popular endgame, VizzarD has a starter guide.

## Mercenary note
Mercenaries (reworked in 3.29) can add a lot of damage. Early picks that sources liked: Fallen Reverend, Blade Ambusher; Kineticist for clear. Check 3.30 changes.
